AI学习之-地址指针和类型

# 例如 (void*)&lucky_number

把它拆开来看：

lucky_number       // 变量本身
&lucky_number      // 取变量的内存地址
(void*)&lucky_number  // 把地址转换成 void* 类型
1
2
3

# 一、& 取地址符

int lucky_number = 7;

printf("%d\n", lucky_number);   // 7        （变量的值）
printf("%p\n", &lucky_number);  // 0x61ff18 （变量的地址）
1
2
3

内存里的样子：

地址        内容
0x61ff18  →  7   ← lucky_number 住在这里

# 二、(void*) 类型转换

void* 是万能指针，可以指向任何类型：

int*    p1 = &lucky_number;   // int 指针
void*   p2 = &lucky_number;   // 需要强制转换成 void*
1
2
指针类型 含义
int* 指向 int 的指针
char* 指向 char 的指针
void* 指向"任意类型"的指针

# 三、为什么要转成 void*？

最常见的场景是传给接受 void* 参数的函数：

#include <stdio.h>

void print_address(void* ptr) {
    printf("地址是：%p\n", ptr);
}

int main() {
    int lucky_number = 7;
    print_address((void*)&lucky_number);  // 必须转成 void* 才能传入
    return 0;
}

# 完整示例

#include <stdio.h>

int main() {
    int lucky_number = 7;

    int*   p1 = &lucky_number;          // int 指针
    void*  p2 = (void*)&lucky_number;   // void 指针

    printf("值        = %d\n",  lucky_number);  // 7
    printf("int* 地址  = %p\n", p1);            // 0x61ff18
    printf("void* 地址 = %p\n", p2);            // 0x61ff18（一样）

    return 0;
}

# 核心注意事项（新手必坑点）

虽然 void* 很灵活，但它有两个非常重要的限制：

不能直接解引用（取值）：因为 void* 没有具体的类型信息，编译器不知道该从那个地址开始读取几个字节的数据（比如 int 读4个字节，double 读8个字节）。如果你想通过它获取 lucky_number 的值，必须先把它强转回原来的类型。

int lucky_number = 10;
void* ptr = (void*)&lucky_number;

// *ptr = 20;       // ❌ 错误！不能直接对 void* 解引用
*(int*)ptr = 20;    // ✅ 正确！先转回 int*，再修改值
1
2
3
4
5

不能直接进行指针运算：普通指针加 1 会根据类型跳过相应的字节数，但 void* 不知道步长，所以不支持 ptr++ 或 ptr + 1 这种运算。 简单来说，这个表达式的目的就是暂时抹去 lucky_number 的具体类型特征，只保留它的内存地址，以便传递给那些“不挑食”（能处理任意类型数据）的函数去使用。

# 总结

&lucky_number       →  取出变量的内存地址（int* 类型）
(void*)&lucky_number →  把地址转成万能指针（void* 类型）
1
2

通俗理解：void* 就像一个通用接头，不管原来是什么类型的地址，都能接上。
