AI学习之-转义字符

# \0 是什么？

\0 是空字符（Null Character），ASCII码值为 0，是C语言字符串的结束标志。

# 一、字符串是怎么存储的？

char str[] = "Hello";
1

你以为存了5个字符，实际上存了6个：

H  e  l  l  o  \0
1
索引 0 1 2 3 4 5
内容 H e l l o \0

\0 自动加在末尾，告诉程序"字符串到这里结束了"。

# 二、没有 \0 会怎样？

#include <stdio.h>

int main() {
    char str[5] = {'H', 'e', 'l', 'l', 'o'};  // 没有 \0
    printf("%s\n", str);  // 危险！会一直读到乱码
    return 0;
}
1

printf 遇到 %s 会一直往后读内存，直到找到 \0 为止，可能输出：

Hello烫烫烫@#$%...  ← 乱码
1

正确写法：

char str[6] = {'H', 'e', 'l', 'l', 'o', '\0'};  // 手动加 \0
1

# 三、\0 的本质

\0 属于转义字符，本质就是数值 0：

'\0' == 0   // true，完全等价
1

常见转义字符对比：

转义字符 含义 ASCII值
\0 空字符（字符串结尾） 0
\n 换行 10
\t 制表符（Tab） 9
\\ 反斜杠 92
\' 单引号 39
\" 双引号 34

# 四、strlen 怎么工作的？

#include <string.h>

char str[] = "Hello";
printf("%d\n", strlen(str));  // 输出 5
1
2
3
4

strlen 的原理就是从头数，直到遇到 \0：

// strlen 的简化实现
int my_strlen(char* s) {
    int count = 0;
    while (s[count] != '\0') {  // 遇到 \0 就停
        count++;
    }
    return count;
}

# 五、\0 vs 0 vs '0'

容易混淆，注意区分：

'\0'  // 空字符，ASCII = 0，字符串结尾
'0'   // 字符0，ASCII = 48，是数字字符
0     // 整数0
1
2
3
printf("%d\n", '\0');  // 0
printf("%d\n", '0');   // 48
1
2

# C语言常见转义字符列表

转义字符 名称 ASCII值 作用
\n 换行符 10 光标移到下一行
\t 水平制表符 9 相当于按Tab键
\r 回车符 13 光标移到本行开头
\0 空字符 0 字符串结束标志
\\ 反斜杠 92 输出一个 \
\' 单引号 39 输出一个 '
\" 双引号 34 输出一个 "
\a 响铃符 7 发出提示音
\b 退格符 8 相当于按Backspace
\f 换页符 12 打印机换页用
\v 垂直制表符 11 垂直跳格

# \n 换行

printf("第一行\n第二行\n第三行\n");

# \\ 输出反斜杠

printf("路径：C:\\Users\\Admin\n");
// 输出：路径：C:\Users\Admin
1
2

# \" 输出双引号

// 输出：他说："你好！"

# 三、\r 回车的特殊行为

\r 把光标移回行首，后面的内容会覆盖前面的：

printf("Hello\rWorld\n");
// 输出：World
// "World" 覆盖了 "Hello" 的前5个字符
1
2
3

进度条常用这个技巧：

for (int i = 0; i <= 100; i++) {
    printf("\r进度：%d%%", i);  // 每次覆盖同一行
}

2

# 四、数值转义

除了上面的，还可以直接用数值表示字符：

// 八进制（\加3位八进制数）
printf("\101");   // 输出 A（八进制101 = 十进制65）

// 十六进制（\x加十六进制数）
printf("\x41");   // 输出 A（十六进制41 = 十进制65）

# 总结

常用：\n 换行   \t Tab   \0 字符串结尾
符号：\\ 反斜杠  \" 双引号  \' 单引号
少用：\r 回车   \a 响铃   \b 退格
