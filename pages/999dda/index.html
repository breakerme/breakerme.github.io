AI学习之-头文件

# 头文件

头文件是扩展名为 .h 的文件，里面存放的是函数声明、宏定义、类型定义等内容。

头文件 (.h)  →  告诉编译器"有这些东西可以用"
源文件 (.c)  →  这些东西的具体实现
1
2

# 为什么需要头文件？

假设你想用 printf()，编译器需要提前知道：

  • 这个函数叫什么名字
  • 接收什么参数
  • 返回什么类型

头文件就是提供这些"说明书"的地方。

# 常用标准头文件一览

头文件 用途 常用内容
<stdio.h> 输入输出 printf scanf fopen
<stdlib.h> 标准库 malloc free exit rand
<string.h> 字符串操作 strlen strcpy strcmp
<math.h> 数学运算 sqrt pow sin cos
<time.h> 时间日期 time clock strftime
<ctype.h> 字符判断 isdigit isalpha toupper
<limits.h> 类型极限值 INT_MAX CHAR_MIN
<stdbool.h> 布尔类型 bool true false

# 头文件实例

#include <stdio.h>

stdio = Standard Input/Output（标准输入输出）

引入后你才能使用：

  • printf() — 打印输出到屏幕
  • scanf() — 从键盘读取输入
  • fopen() / fclose() — 文件操作
  • 等等…

#include <stdlib.h>

stdlib = Standard Library（标准库）

引入后你才能使用：

  • malloc() / free() — 动态内存分配
  • exit() — 退出程序
  • rand() — 生成随机数
  • atoi() — 字符串转整数
  • 等等…

打个比方：

就像做饭前要先把工具拿出来——#include 就是"打开工具箱"的动作，没有它，编译器不知道 printf 是什么东西，会报错。

# 开头是什么意思？

#include 是预处理指令，在正式编译前就会被处理——编译器会把 <stdio.h> 文件的内容直接"复制粘贴"到你的代码里。

# 两种引入方式的区别

#include <stdio.h>   // 尖括号：系统头文件
#include "myfile.h"  // 双引号：自定义头文件

#define MYMATH_H

int add(int a, int b);
int subtract(int a, int b);

#endif

# 头文件守卫是什么？

#ifndef MYMATH_H    // 如果 MYMATH_H 没有被定义过
#define MYMATH_H    // 就定义它，并编译下面的内容

// ... 头文件内容 ...

#endif              // 结束
1
2
3
4
5
6

作用：防止同一个头文件被重复引入导致报错。

比如 A 引入了 mymath.h，B 也引入了 mymath.h，main 同时引入 A 和 B，没有守卫就会报"重复定义"的错误。

也可以用更简洁的写法（现代编译器都支持）：

#pragma once   // 效果相同，更简洁

# 总结

头文件 (.h)  =  函数/类型的"目录"，告诉编译器有什么
源文件 (.c)  =  函数的"正文"，具体怎么实现

2

头文件是C语言模块化编程的基础，让大型项目可以拆分成多个文件协作开发。
