AI学习之-数组长度

# 求数组长度标准方法：sizeof

int nums[] = {2, 7, 11, 15};
int len = sizeof(nums) / sizeof(nums[0]);
printf("%d\n", len);  // 输出 4
1
2
3

原理：

sizeof(nums)      = 16  （整个数组占16字节，4个int × 4字节）
sizeof(nums[0])   = 4   （一个int占4字节）
16 / 4 = 4              （数组长度）

# 各类型演示

int    a[] = {1, 2, 3, 4, 5};
double b[] = {1.1, 2.2, 3.3};
char   c[] = "Hello";

printf("%d\n", sizeof(a) / sizeof(a[0]));  // 5
printf("%d\n", sizeof(b) / sizeof(b[0]));  // 3
printf("%d\n", sizeof(c) / sizeof(c[0]));  // 6（含\0）

# ⚠️ 传入函数后就失效了

这是C语言最常见的坑：

void print_len(int arr[]) {
    // 错误！arr 已退化成指针，sizeof只返回指针大小
    int len = sizeof(arr) / sizeof(arr[0]);
    printf("%d\n", len);  // 输出 2（64位系统指针8字节 / 4 = 2）
}

int main() {
    int nums[] = {2, 7, 11, 15};
    print_len(nums);  // 本来应该输出4，实际输出2 ❌
}

解决方法：把长度单独传进去

void print_len(int arr[], int len) {  // 额外传入 len
    printf("%d\n", len);  // ✅ 正确
}

int main() {
    int nums[] = {2, 7, 11, 15};
    int len = sizeof(nums) / sizeof(nums[0]);
    print_len(nums, len);  // 把长度传进去
}

# 常用宏封装

很多项目会定义一个宏简化写法：

#define ARRAY_LEN(arr)  (sizeof(arr) / sizeof((arr)[0]))

int nums[] = {2, 7, 11, 15};
printf("%d\n", ARRAY_LEN(nums));  // 4
1
2
3
4

# 总结

✅ 正确：sizeof(arr) / sizeof(arr[0])  在定义数组的地方用
❌ 错误：在函数参数里用 sizeof 求长度
💡 方案：定义时算好长度，作为参数传入函数
