AI学习之-GCC

# GCC 编译器

GCC = GNU Compiler Collection（GNU 编译器集合）

# GCC是什么？

GCC 是一个把写的源代码翻译成电脑能执行的机器码的工具。

写的 .c 文件  →  GCC 编译  →  可执行程序
1

# 为什么需要编译器？

电脑只认识 0 和 1，看不懂 printf("Hello") 这样的人类语言。GCC 就是中间的"翻译官"。

# GCC 支持哪些语言？

虽然叫"C编译器"，但它支持很多语言：

语言 命令
C gcc
C++ g++
Fortran gfortran
等等…

# 基本使用方法

# 编译一个 C 文件
gcc hello.c -o hello

# 运行生成的程序
./hello

# GCC 编译的四个步骤

源代码 (.c)
    ↓  1. 预处理   处理 #include、#define 等
    ↓  2. 编译     转换成汇编语言
    ↓  3. 汇编     转换成机器码 (.o 文件)
    ↓  4. 链接     合并成最终可执行文件

# GNU 是什么？

GNU 是一个开源软件项目，GCC 是它的核心工具之一。GCC 免费、开源，是目前世界上使用最广泛的 C/C++ 编译器，Linux 系统、很多嵌入式设备都靠它编译。
