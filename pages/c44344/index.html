AI学习之-宏

# 什么是宏？

宏是用 #define 定义的"文本替换规则"，在编译前由预处理器把代码里的宏名全部替换成对应内容。

源代码  →  预处理器替换宏  →  编译器编译  →  可执行程序
1

# 一、常量宏

最简单的用法，给常量起个名字：

#include <stdio.h>

#define PI 3.14159
#define MAX 100
#define APP_NAME "MyApp"

int main() {
    printf("圆周率 = %f\n", PI);
    printf("最大值 = %d\n", MAX);
    printf("程序名 = %s\n", APP_NAME);
    return 0;
}

# 二、函数宏

宏也可以带参数，像函数一样使用：

#include <stdio.h>

#define SQUARE(x)  ((x) * (x))
#define MAX(a, b)  ((a) > (b) ? (a) : (b))
#define ABS(x)     ((x) < 0 ? -(x) : (x))

int main() {
    printf("%d\n", SQUARE(5));      // 25
    printf("%d\n", MAX(3, 7));      // 7
    printf("%d\n", ABS(-10));       // 10
    return 0;
}

# 三、为什么要加括号？

函数宏一定要加括号，否则会出错：

#define SQUARE_BAD(x)   x * x       // 危险！
#define SQUARE_GOOD(x)  ((x) * (x)) // 安全

printf("%d\n", SQUARE_BAD(1 + 2));
// 展开成：1 + 2 * 1 + 2 = 5   ❌ 错误

printf("%d\n", SQUARE_GOOD(1 + 2));
// 展开成：((1 + 2) * (1 + 2)) = 9  ✅ 正确

# 四、条件编译宏

控制哪些代码参与编译：

#define DEBUG   // 定义了 DEBUG

#ifdef DEBUG
    printf("调试信息：x = %d\n", x);  // DEBUG模式下编译
#endif

#ifndef RELEASE
    printf("非发布版本\n");            // 没定义RELEASE时编译
#endif

之前讲过的 #ifndef 守卫本质上也是宏：

# 宏 vs 函数 vs 常量

宏 函数 const常量
有无类型检查 ❌ 没有 ✅ 有 ✅ 有
运行速度 ✅ 快（直接替换） 略慢（有调用开销） ✅ 快
调试难度 ❌ 较难 ✅ 容易 ✅ 容易
适合场景 简单替换、条件编译 复杂逻辑 常量值

# 总结

宏 = 编译前的文本替换工具

常量宏  →  #define PI 3.14159
函数宏  →  #define SQUARE(x) ((x)*(x))
条件宏  →  #ifdef / #ifndef / #endif
