# 数据透视表

# 数据透视表应用场景

通常用在处理海量数据的时候，数据透视表可以提供弹性的灵活界面，可以轻松探索资料，协助进行决策。

# 应用方式

  • 鼠标点击表格中的任意单元格区域之后选择插入→数据透视表
  • 在弹出的窗口中会自动识别表格区域，但不一定完全正确，要注意检查一下
  • 同时你可以选择放置数据透视表的位置→点击确定
  • 界面右侧出现数据透视表字段，里面涵盖所有标题，我们可以勾选这些标题，将其放入数据透视表中，也可以拖动它到行或列中，可以自动计算总和
  • 数据透视表中还具备了排序和筛选功能，可以点击表格中左上角的三角形按钮进行筛选

# 与分类汇总的区别

分类汇总：对某列数据排序，然后再对该列里面数据进行分类，再进行汇总，最后得出的结果是最后得出的结果是可以查看每一类的明细情况

数据透视表：更强大，除了可以实现分类汇总外，还可以实现复杂的分类汇总操作，同时还有一些其他的操作，比如制作动态交互图表等，包括制作报表等

# 数据透视表的重要区域

字段区域：（需要拖动字段到行和值区域）

  • 行：表示从数据维度的方向看数据，可以看到数据的分布变化
  • 值区域：是对应的统计项，可以选中求和项，选择值和字段的设置，选择计算类型，选择你想要的统计计算类型。也可以选择值显示方式，列汇总百分比，来计算某一类数据的占比
  • 列：对应数据
  • 筛选器：通过筛选器，可以让3个区域中，只显示你想要的数据，小提示(筛选器中的字段，不能再放到其他区域中，否则会自动从筛选器中移除)

# 数据透视表之切片器

  • 插入切片器：选择数据透视表任意单元格，点击数据透视表分析，点击插入切片器，然后在出现的弹框中勾选你要筛选的数据
  • 切片器设置：选中切片器，点击菜单栏中的切片器设置，在切片器设置中可以取消页眉显示，以及隐藏没有数据的项
  • 切片器的排列方式：将切片器按钮进行横向或竖向排列，在按钮区域改变列数，高度，宽度。
  • 切片器样式：可以调整颜色。自定义：字体，边框，填充
  • 双击数据透视表某一格，会形成新的数据透视表
